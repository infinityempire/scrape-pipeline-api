# Sources verified for the static-site pipeline

- GitHub Pages is available in public repositories with GitHub Free; private repositories require a qualifying paid plan. Source: https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages
- GitHub Pages custom workflows use an uploaded static artifact and the official Pages deployment actions. Source: https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages
- Upstash Redis REST accepts authenticated HTTPS command arrays, including `SET` with `EX` TTL. Source: https://upstash.com/docs/redis/features/restapi
- Koyeb’s February 2026 announcement says new users need a valid payment method and a paid plan; its former Free Instance cannot fulfill a $0 deployment for a new account. Source: https://www.koyeb.com/blog/koyeb-is-joining-mistral-ai-to-build-the-future-of-ai-infrastructure
